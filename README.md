# 알프스 영업관리

TM 직원이 전화하고 상황을 등록하면, 영업사원이 확인하고 미팅·계약까지 이어서 기록하는 휴대폰용 앱입니다.
고객(매장)마다 '기록과 대화' 창이 있어 TM·영업·대표가 같은 화면에서 소통합니다. 웹사이트·정산 앱과 따로 배포합니다.

## 역할과 담당
고객마다 역할별 담당자 3명을 따로 정하고, 단계가 넘어가면 그 단계 담당이 이어받습니다. 등록된 팀원은 모든 고객·기록·대화를 함께 봅니다.
1. **TM · 미팅 전 담당** — 고객 등록, 통화 기록(다음 연락 일정), 미팅 예약
2. **대면 미팅 담당** — 예약 확인, 방문 미팅 결과(몇 번째 미팅인지 자동), 계약 상황
3. **관리 담당** — 계약 후 관리 기록(방문·재발주·교육)과 다음 관리 일정

단계: 신규 → 통화 중(TM) → 미팅 예약 → 미팅 진행 → 계약 협의(미팅 담당) → 계약·관리(관리 담당) · 보류 · 무산

## 대시보드
- 오늘 연락 · 오늘 방문 · 오늘 관리 숫자(이번 주 합계 함께) — 누르면 그 종류만 보기
- **오늘** 목록과 **이번 주(월~일)** 날짜별 목록. 각 줄의 네모를 누르면 완료 체크(누가 체크했는지 팀 전체에 보이고 기록에도 남음), ☎로 바로 전화
- 지난 날 체크 안 한 일은 '밀림'으로 오늘 목록에 남음
- 내 담당 / 팀 전체 전환, 확인할 미팅 예약, 결과를 안 적은 미팅, 통화 전 신규 고객, 팀원 최근 소식

화면: 대시보드 · 고객(검색·단계별·내 담당) · 현황(단계별 고객 수, 이번 달 계약, 팀원별 TM·미팅·관리 실적) · 팀원(누구나 사람 등록·역할 지정)

## 처음 한 번 설정
### 1. Firebase (무료 요금제로 충분)
1. https://console.firebase.google.com → 프로젝트 추가 (예: alfs-sales). 정산 앱과 같은 프로젝트를 써도 되지만, 그 경우 규칙을 합쳐야 하므로 새 프로젝트를 권합니다.
2. Authentication → 로그인 방법 → **Google** 사용 설정
3. Firestore Database → 데이터베이스 만들기 (asia-northeast3 서울) → **규칙** 탭에 `firestore.rules` 를 통째로 붙여 넣고 게시
4. 프로젝트 설정 → 내 앱 → 웹 앱 추가 → `firebaseConfig` 값을 Vercel 환경 변수에 넣음

대표 계정은 `firestore.rules` 의 이메일과 `src/config.js` 의 `ADMIN_EMAILS` 두 곳에 같게 적습니다. 이 계정으로 처음 로그인하면 바로 '대표'가 됩니다.

### 2. GitHub → Vercel
1. GitHub에 새 저장소(예: alfs-sales)를 만들고 이 폴더의 파일·폴더를 전부 올림
2. Vercel → Add New → Project → 저장소 Import (Root Directory 비워 둠)
3. 환경 변수: `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, `VITE_FIREBASE_PROJECT_ID`, `VITE_FIREBASE_APP_ID`, `VITE_FIREBASE_STORAGE_BUCKET`, `VITE_FIREBASE_MESSAGING_SENDER_ID`
4. 배포된 주소를 Firebase → Authentication → 설정 → **승인된 도메인**에 추가

### 3. 팀원 등록
- **팀원** 탭에서 이름·Google 이메일·역할(TM·미팅 전 / 대면 미팅 / 관리 / 대표)을 적어 등록 → 그 사람이 앱 주소로 들어와 그 Google 계정으로 로그인하면 바로 그 역할로 시작
- 등록 없이 먼저 로그인한 사람은 '역할을 기다리는 사람'에 뜨고, 팀원 누구나 역할을 눌러 정해 줌
- 팀원 누구나 사람을 등록하고, 역할을 바꾸고, 팀에서 뺄 수 있음 (자기 역할은 다른 팀원이 바꿈)
- 휴대폰에서 '홈 화면에 추가'하면 앱처럼 열림. 카카오톡 안에서는 Google 로그인이 막히니 기본 브라우저로 열기

## 동작 방식
- Firebase 값이 없으면 체험 모드(이 브라우저에만 저장, 빈 상태로 시작)로 동작합니다.
- 고객 정보와 기록은 팀원(TM·영업·대표) 모두가 함께 봅니다. 역할이 정해지기 전 계정은 볼 수 없습니다. 고객 삭제는 대표만 할 수 있습니다. 기록은 본인 이름으로만 남고 고칠 수 없습니다.
- 데이터: Firestore `members/{uid}`, `invites/{이메일}`, `leads/{id}`, `leads/{id}/logs/{id}` (자세한 내용은 `src/store.js` 맨 위 설명)

## 개발
`npm install` → `npm run dev` · `npm run build`
